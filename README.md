# Age Calculator

A simple and responsive **Age Calculator Web App** built using **HTML, CSS, and JavaScript**.
It allows users to select their birth date and instantly calculates their exact age in **years, months, and days**.

## Features

- Select date of birth using a date picker
- Calculates exact age (years, months, days)
- Fully responsive design (mobile, tablet, desktop)
- Fast and lightweight (no external libraries)
- Clean and modern UI

## Technologies Used

- **HTML5** – Structure of the app
- **CSS3** – Styling and responsiveness
- **JavaScript (Vanilla JS)** – Logic and calculations

## Project Structure

```
Age-Calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## 💡 How It Works

- User selects a birth date
- JavaScript compares it with the current date
- Calculates difference in:
  - Years
  - Months
  - Days

- Displays result dynamically on screen
